HRNet-W32 COCO weights (hrnet_w32_coco_256x192.pth, about 110 MB) are downloaded here automatically the first
time you run:  python pose_backend.py --selftest   (or pose_extract.py).

No internet on the computer? Download this file on another computer and copy it here with this exact name:
  https://download.openmmlab.com/mmpose/top_down/hrnet/hrnet_w32_coco_256x192-c78dce93_20200708.pth
  -> weights/hrnet_w32_coco_256x192.pth
The official file pose_hrnet_w32_256x192.pth (HRNet model zoo) also works if you put it here.
The person detector weights (torchvision Faster R-CNN, about 160 MB) are downloaded by torchvision into ~/.cache/torch.
